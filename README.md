# PawMemory

A personal memory for a pet. This demo follows one dog, Momo, from saved moments to a caregiver brief.

Ask PawMemory and Remember this talk to a local ClawMax agent at `http://localhost:3001`. The Vite dev server proxies `/api` to that address. The production build does not include that proxy.

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints. ClawMax needs to be running on port 3001 for live answers. The rest of the screen works without it.
